# Rimvio 플랫폼 비전 (Platform Vision)

> **대상:** 창업자, PM, 다음 AI 에이전트 — "이 방향으로 깊게 가면 결국 어떤 플랫폼이 되는가"
>
> **관련 문서:** [RIMVIO_PRODUCT.md](./RIMVIO_PRODUCT.md) · [RIMVIO_CONSTITUTION.md](./RIMVIO_CONSTITUTION.md) · [ACTION_OS_SPINE.md](./ACTION_OS_SPINE.md)
>
> **한 줄 비전:** **맥락이 연결되면, 대신 실행합니다.**
>
> **최종 형태:** 슈퍼앱이 아니라 **의도(intent)를 실행으로 정산해주는 개인 실행 계층(Execution Layer).**

---

## 0. 왜 이 비전인가

"검색 + 예약 + 중고거래"를 각각 하는 앱은 이미 레드오션(구글/네이버, 캐치테이블/야놀자, 당근/번개장터)이다.
빈 자리는 **기능의 개수**가 아니라 **연결 방식**에 있다.

- 기존: 검색은 검색앱, 예약은 예약앱, 거래는 거래앱 → **사람이 매번 앱을 갈아타며 맥락을 직접 옮김**
- Rimvio: 흩어진 자원(장소·사람·일정·링크)을 신경망처럼 잇고, **조건이 맞으면 대신 실행**

> 핵심 문장: **맥락이 연결되면, Rimvio가 다시 실행한다.**

---

## 1. 플랫폼 진화 4단계

### 1단계 — 맥락 실행 도구 (지금)

- 흩어진 장소·사람·일정·링크를 모아 조건이 맞으면 한두 탭으로 실행
- 성격: **똑똑한 개인 비서 앱**
- 남들도 흉내 가능한 구간 (해자 아직 없음)

### 2단계 — 개인 Context OS

- 자원이 신경망처럼 연결되고 `@` registry로 재사용
- 사용자가 "찾는" 게 아니라 Rimvio가 "때가 됐다"고 먼저 준비 (Proactive prep)
- 성격: **내 삶의 실행 운영체제** — 앱이 아니라 OS 레이어

### 3단계 — 수요 측 실행 관문 (양면 플랫폼)

여기가 진짜 커지는 지점.

- 사용자는 **"뭘 원한다"는 맥락(조건)** 만 생성
- 예약·거래·이동 같은 실제 공급(식당·판매자·이동수단)은 **Rimvio가 조건에 맞춰 매칭·실행**
- Rimvio = **수요 측 OS**, 공급자는 여기 붙어야 함
- 대비:
  - 검색앱 = 정보만 줌 (실행 안 함)
  - 예약앱 = 하나의 공급만 붙음
  - **Rimvio = 여러 공급을 맥락 하나로 오케스트레이션** ← 최종 해자

### 4단계 — 실행 프로토콜 / 인프라

- 다른 앱·서비스가 Rimvio의 `@` 컨트랙트를 통해 "실행 요청"을 받음
- Rimvio가 UI 앱이 아니라 **실행이 오가는 표준 규격(프로토콜)** 이 됨
- 성격: **"인텐트의 결제망"** — 안 보이지만 다 통과함

---

## 2. 한 줄 요약

> **검색·예약·거래 앱 → 개인 Context OS → 수요를 실행으로 바꾸는 양면 플랫폼 → 실행 인프라(프로토콜)**

슈퍼앱은 **기능**을 모으고, Rimvio는 **맥락과 실행**을 모은다. 층위가 다르다.

---

## 3. 경쟁 포지셔닝

| 유형 | 대표 | 한계 (Rimvio와의 차이) |
|---|---|---|
| 검색·발견 | 구글·네이버·인스타 저장 | 정보만 줌, 실행 안 함 |
| 예약 | 캐치테이블·야놀자·OpenTable | 단일 공급만 연결 |
| 중고거래 | 당근·번개장터·크림 | 단일 도메인 |
| 슈퍼앱 | 위챗·그랩·토스 | 기능은 모으나 미니앱끼리 **단절**, 맥락으로 안 이어짐 |
| AI 어시스턴트 | 퍼플렉시티·ChatGPT actions | 개인 자원을 SSOT로 물고 재실행하는 **개인 OS**는 아님 |

방어선 = **"맥락 연결 → 자동 재실행"** 축. 현재 시장에 거의 비어 있음.

---

## 4. 구현 규율 (중요)

비전은 4단계지만 **구현은 1단계 수직 슬라이스부터.** 이 순서를 지켜야 3~4단계가 실제로 열린다.

워크스페이스 규칙(`.cursor/rules/action-os-spine.mdc`, Context OS 레이어법)상 **지금은 아래 한 루프에만 집중하도록 잠겨 있음:**

```
Context (calendar · notification · chat · link)
 → @ Action Contract Registry
 → Proactive prep surface (MAIN + AUX)
 → Archive fold + telemetry
 → Learning rollup → MAIN ranking
```

- 4단계 비전(마켓플레이스·프로토콜)을 **지금 코드로 당겨오지 말 것** (frozen backlog)
- 비전 문서는 방향 정렬용이며, 레이어 소유권/금지 의존성 규칙을 위반하지 않는다
