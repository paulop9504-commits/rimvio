## 준비 (당신만)

- Rimvio dev 또는 TestFlight/PWA 링크
- 테스트 결제 (샌드박스) 확인
- 설정 → **여행 신원** 미리 저장 (이름·연락처)
- 지구 카메라 **도쿄** 근처면 더 좋음

## 3분 플로우

### 1. 발견 (30초)
채팅에 입력:
```
도쿄 3박 숙소 찾아줘
```
→ 지도에 핀 뜨면 OK

### 2. 고르기 (45초)
1. 마음에 드는 **숙소 핀** 탭
2. **맥락에 고정** (핀 버튼)
3. **객실 선택** → API 객실명(예: Deluxe King) 보이는지 확인
4. **「이 객실로 예약」** 탭

### 3. 결제 (60초)
```
확인 → 결제 → 완료
```
- 카드 / 카카오 / 토스 중 하나
- **「결제를 마쳤어요」** 토스트 나오면 성공

### 4. Day 2 recall (45초) ⭐
1. **앱 완전 종료** (탭 닫기 / 백그라운드 kill)
2. 다시 열기
3. **도쿄 맥락 핀** 탭
4. 확인:
   - 핀에 **「확정 1건」** 배지
   - Hub에 **「숙소 확정」** + **맥락 기록**
